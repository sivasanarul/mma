# Roadmap

- Refactor the procedural optimizer into a documented reusable C++ API.
- Add validation against published MMA benchmark problems.
- Add objective and constraint callback interfaces.
- Support arbitrary problem sizes without temporary dense allocations.
- Add the complete GCMMA conservative-approximation workflow.
- Add numerical failure diagnostics and iteration reporting.
- Add sanitizer, GCC, and Clang CI jobs.
- Package releases through CMake install and package configuration targets.
